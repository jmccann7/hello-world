Color!

If you really want to get advanced with color, there is a lot more that you can can do and you probably want a style sheet--we're not going to get into that level of work. We can do major color changes however.

Please note there are like 140 color names that HTML knows.

I can set the color for a specific part

or just the text.

If you want to do a lot with color, you probably want to use 'div'.

Be careful with color. Unless you really have an eye for it, it is okay to be simple.
